# 統合台帳 入力の仕方（商品担当向け）

**発注したら「発注明細入力」シートに1品目＝1行で書く。** 明細ID・発注ID・金額(円)・会計区分は自動で入るので触らない（灰色の列）。

| 列 | 書くこと |
|---|---|
| ブランド | Yunth / Brighte / Straine / LOEM から選ぶ |
| 仕入先コード | 仕入先マスタのコード |
| 発注日・稟議AP | 同じ仕入先・同じ日・同じAPの行は、自動で同じ発注IDにまとまる |
| 通貨・換算レート | 円以外はレート必須（空だと金額が出ず、要確認になる） |
| 種別 | 商品 / 資材 / 販促物 / 開発費 / 金型 |
| 単価・仕入先単位・入数 | 単価は仕入先の単位あたり。箱単価で倉庫はバラ数なら「入数」に箱の入り数 |
| 数量 | **倉庫で数える単位**（入荷実績と同じ単位） |
| 納期予定月 | 2026/12 の形 |
| 状態 | 取り消したら「取消」に変える（行は消さない） |

- **要確認** 列に文字が出たら、その内容を直す
- 右下に「この編集の自動処理を…あとに回しました」と出たら、NX取り込みなどほかの処理が動いていただけ。そのままでよい（次に発注明細入力・便・出荷明細のどれかを編集したときか、1時間ごとの更新のときに、IDや金額が自動で入る）
- **支払**：「支払」シートに、発注IDと区分（前金／中間金／後金）、予定日・金額を書く。送金したら送金日を入れる
- **NX以外のフォワーダーの便**：「便」シートに shipper・H B/L・ETD・ETA を書くと便IDが付く。中身は「出荷明細」シートに、便IDと品目・数量・明細IDを書いて「紐付状態」を確定にする
- **NXの便**：取り込みで自動で入る。「出荷明細」の候補を見て、正しければ明細IDを確認して「紐付状態」を確定にする（確定にすると入荷予定ができる）
- 見るだけのときは `V_` で始まるシート（ヨミ表・発注残・輸送中・入荷予定・突合エラー）。1時間ごとに更新、メニュー「統合台帳 > ビュー更新」ですぐ更新
