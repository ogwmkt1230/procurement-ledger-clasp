## シートから分かっていること（2026-11-25 時点）

| 仕組み | シート | 読んでいる範囲（シート上の見出しから推定） | 書く先 |
|---|---|---|---|
| 入荷予定メール下書き | `フォーム` | H〜L列：いつ・メールの内容・件名・メール本文URL（Googleドキュメント）・月度。宛先は C〜D列（会社名・宛先・To・Cc） | Gmail 下書き |
| 予定自動登録 | `予定自動登録` | D〜Q列：件名・場所・説明・モール・商品名・商品ID・予約放出日付・商品入荷日・入荷数量・CSV送付日付・開始/終了時間・インポート日付・カレンダーに登録 | Googleカレンダー（1時間ごと） |
| 入荷タブ | `入荷（Yunth）` ほか | A〜F列：元々納品月・実際納品月・商品名・商品コード・入荷予定日・入荷予定数 | — |

`予定自動登録` の「入荷数量」列が `#VALUE!` になっている行があり、入荷タブを参照する式が切れている可能性がある。

## 手順

1. `clasp clone <04のscriptId>` で取得し、下の表を埋める

   | 関数名 | 読むシート | 読む列（番号固定か見出し名か） | 書く先 |
   |---|---|---|---|
   |  |  |  |  |

2. 読み元をまとめる関数を足す。台帳側の `V_入荷予定` は、先頭6列が入荷タブのA〜F列と同じ並び。

   ```js
   // 04側に追加。brand が PROTEIN のときは従来どおり04のタブを読む
   function getInboundRows_(brand) {
     if (brand === 'PROTEIN') return legacyRows_('入荷（PROTEIN）');
     var v = SpreadsheetApp.openById(LEDGER_ID).getSheetByName('V_入荷予定').getDataRange().getValues();
     var head = v.shift();
     var bi = head.indexOf('ブランド');
     return v.filter(function (r) { return r[bi] === brand; }).map(function (r) { return r.slice(0, 6); });
   }
   ```

3. 既存の呼び出し元を `getInboundRows_` に置き換える。列番号を直接使っている箇所は、A〜F列の並びが同じなのでそのまま動く
4. テスト用のコピーで、来月分のメール下書きの件名・本文と、カレンダー登録件数が改修前と同じことを、めぐさんと確認する
